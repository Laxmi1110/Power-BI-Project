# Adidas Data Analysis Dashboard

## Project Overview

This project is an interactive Adidas Data Analysis Dashboard created using Microsoft Power BI.

The dashboard analyzes Adidas product data to understand pricing, product availability, stock status, categories, colors, and geographic distribution.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Analysis

- Average List Price vs Average Sale Price
- Product Stock Analysis
- Out-of-Stock Products by Color
- Product Availability by Country
- Product Analysis by Category and Subcategory
- Average Available Units
- In-Stock Percentage
- Rating and Size Count Analysis

## Project Overview

This project is an interactive **Student Spending Dashboard** created using Microsoft Excel.

The dashboard analyzes student financial data to understand spending patterns, income, payment methods, tuition expenses, and spending across different categories.

## Objectives

- Analyze student income and spending patterns.
- Compare spending across different categories.
- Analyze payment method usage by gender.
- Compare financial aid across different years in school.
- Analyze tuition expenses by subject.
- Understand the relationship between student age, income, and spending.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Charts
- Data Cleaning
- Data Analysis
